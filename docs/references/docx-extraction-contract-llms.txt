# DOCX extraction API and evidence wire contract

Contract for future cards, not remotely existing implementation. User approved conservative image retention on 2026-09-08; legacy enum names do not authorize automatic exclusion.

## Kotlin API

Package `nz.myinspection.core.report.importing.docx.extract`; unmarked members public, standard data-class methods. Only occurrence defaults; nullable arguments required. No sorting/deduplication/coercion.

```kotlin
data class SourceLocation(val part: String, val ordinal: Int, val occurrence: Int = 0)
data class ExtractedText(val source: SourceLocation, val raw: String) { val normalized: String }
data class ExtractedItem(val room: String?, val name: ExtractedText, val status: ExtractedText?, val comment: ExtractedText?)
enum class FragmentRole { UNKNOWN, ROOM, ITEM, STATUS, COMMENT, LABEL, IDENTITY, CAPTION, NARRATIVE }
data class ExtractedFragment(val role: FragmentRole, val text: ExtractedText)
enum class ExtractionWarningCode {
  UNRESOLVED_TEXT, PAGINATION_EXCLUDED, METADATA_EXCLUDED, URL_EXCLUDED,
  AMBIGUOUS_COLUMNS, UNRESOLVED_NARRATIVE, AMBIGUOUS_CAPTIONS,
  LAYOUT_IMAGE_EXCLUDED, MISSING_IMAGE, IMAGE_REVIEW_REQUIRED
}
data class ExtractionWarning(val code: ExtractionWarningCode, val source: SourceLocation?)
data class IdentityCandidate(val field: String, val text: ExtractedText)
data class CaptionCandidate(val number: String, val text: ExtractedText)
data class ExtractedImage(val part: String, val sha256: String, val width: Int?, val height: Int?)
enum class DrawingKind { INLINE, ANCHORED }
data class DrawingPlacement(val source: SourceLocation, val kind: DrawingKind, val imagePart: String?)
class DocxExtractionManifest internal constructor(
  items: List<ExtractedItem>, fragments: List<ExtractedFragment>, warnings: List<ExtractionWarning>,
  identity: List<IdentityCandidate>, summaryCandidates: List<ExtractedText>, captions: List<CaptionCandidate>,
  images: List<ExtractedImage>, placements: List<DrawingPlacement>
) {
  val items: List<ExtractedItem>; val fragments: List<ExtractedFragment>
  val warnings: List<ExtractionWarning>; val identity: List<IdentityCandidate>
  val summaryCandidates: List<ExtractedText>; val captions: List<CaptionCandidate>
  val images: List<ExtractedImage>; val placements: List<DrawingPlacement>
  val extractorVersion: String // exactly "DOCX-EXTRACT-1"
  val normalizedDigest: String // eagerly computed SHA-256, lowercase 64 hex digits
}
internal fun <T> immutable(values: List<T>): List<T>
class DocxReportExtractor { fun extract(source: DocxPackage): DocxExtractionManifest }
```

`DocxPackage`/`DocxPart` belong to the reader's `nz.myinspection.core.report.importing.docx.package` (escape `package` in Kotlin). Extractor: public no-arg constructor, per-call state, bounded input, no writes/network/native mapping.
Copy all eight lists into unmodifiable views; caller edits cannot alter values/digest. Published clear/add/set after mutable casts throw `UnsupportedOperationException`; elements contain no mutable collections.

`normalized` = NFC(raw), Kotlin `String.trim()` using `Char.isWhitespace`, then collapse runs of only U+0020/0009/000A/000B/000C/000D to U+0020. Preserve raw/source; no case folding. Other interior whitespace survives except NFC mappings (U+2000→2002, U+2001→2003). The golden values below pin accents and whitespace.

## DOCX-EXTRACT-1 bytes

Define `F(s)` as signed 32-bit big-endian UTF-8 byte length then exactly those bytes, without BOM/terminator. `F(null)` is `ff ff ff ff` only; `F("")` is `00 00 00 00`. UTF-8 encoder reports malformed/unmappable input; any isolated/misordered UTF-16 surrogate in any emitted string raises `java.nio.charset.CharacterCodingException`, never replacement bytes. Decimal integers use ordinary signed base-10 `Int.toString()` without padding. Emit `F("DOCX-EXTRACT-1")`, then groups in the following order, irrespective of constructor argument order. Each group starts `F(groupName), F(decimalCount)`, followed by all entries in supplied list order. Do not sort or deduplicate. Hash the concatenated bytes once with SHA-256.

`L(location)` emits `F(part), F(decimal ordinal), F(decimal occurrence)`; null location emits three null fields. `T(text)` emits `L(source), F(raw), F(normalized)`; null text emits five null fields.

| Group | Each entry |
|---|---|
| fragments | F(role.name), T(text) |
| items | F(room), T(name), T(status), T(comment) |
| identity | F(field), T(text) |
| summary | T(text) from summaryCandidates |
| captions | F(number), T(text) |
| images | F(part), F(sha256), F(width?.decimal), F(height?.decimal) |
| placements | L(source), F(kind.name), F(imagePart) |
| warnings | F(code.name), L(source) |

Image SHA is text, not decoded bytes. This is not the native inspection hash.

## Independent golden vectors

F/L/T and these literal inputs define independent wire vectors. Empty all eight lists: 17 fields, 151 bytes; SHA-256 `dade39f717f3be4181d418a24a67814806e63b7f73f37dc559aa06aaa886993a`. Literal field sequence is `DOCX-EXTRACT-1,fragments,0,items,0,identity,0,summary,0,captions,0,images,0,placements,0,warnings,0` (commas are separators, not bytes).

## Internal XML-tree contract

```kotlin
internal const val W: String = "http://schemas.openxmlformats.org/wordprocessingml/2006/main"
internal class Element(val uri: String, val name: String, val attrs: Map<String, String>, val parent: Element?) {
  val children: ArrayList<Element>; val value: StringBuilder
  fun isWord(local: String): Boolean
  fun descendants(): Sequence<Element>
  fun ancestor(local: String): Element?
  fun attr(local: String): String?
}
internal fun parse(part: DocxPart): Element
```

`children`/`value` start empty (mutable internal tree). Parsing is namespace-aware and nonvalidating. Attr keys are `namespaceURI|localName`; `attr(local)` prefers `W|local` over `|local`, ignoring other namespaces. `isWord` tests exact URI and local name. `descendants` yields self then depth-first descendants in encounter order; `ancestor` excludes self and chooses the nearest Word ancestor. Parent links are exact. Direct character events, CDATA and UTF-8 text append to the current node only, never flattening descendants. Prefix choice does not change expanded names.

Parse `part.copyBytes()` entirely in memory. Malformed XML, any DOCTYPE (including inert/internal expansion), external general/parameter entities and external subsets reject before target-file/network access with `IllegalArgumentException("DOCX_XML")`, no nested cause or source leakage. Calibrate and restore a test-only file/URL I/O guard. Package byte/depth/node/text limits remain upstream; no independent sandbox. Test namespace collisions, attr precedence, ancestors and ordering positively.
